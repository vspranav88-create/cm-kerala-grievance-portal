# 07 — User Guide

## Citizen

1. Browse the public pages to learn about the portal and departments.
2. Choose Register and create an account, then sign in.
3. Choose Submit Grievance. Enter district, category, subject and a description of at least 20 characters. Attach an optional JPG, PNG or PDF file up to 5 MB.
4. If AI analysis is available, review its suggested department, category, priority and summary. Treat it as a suggestion; correct details where needed.
5. Submit the grievance and save the generated reference ID.
6. Use Track Grievance with the reference ID to see the public status and progress history. Sign in to see your own dashboard and grievance details.
7. Once a case is resolved, submit a 1–5 rating and optional comment. If the issue remains unresolved, use the reopen option and explain why.

## CMO administrator

1. Sign in using a provisioned CMO account.
2. Open the dashboard to review totals, pending/overdue work and breakdowns.
3. Open a grievance, review the description, history and any AI suggestion.
4. Select the responsible department and optionally an officer. Add a clear assignment remark and forward the grievance.
5. Monitor progress. Add internal remarks or escalate when needed.
6. Review officer action reports. Choose resolve when the report closes the issue or send back when more work is needed; include a remark.

## Department officer

1. Sign in using the officer account provisioned for your department.
2. Open the officer dashboard and review grievances assigned to that department.
3. Open a case and inspect its details and citizen attachments.
4. Update progress to In Progress with an investigation remark.
5. Submit an action-taken report of at least 10 characters. It is sent to the CMO for review; officers do not directly resolve a grievance.
